Third-party notices for Qwen3 TTS Android (llama.cpp)

The Android app is derived from Danmoreng/qwen3-tts-android.
Source: https://github.com/Danmoreng/qwen3-tts-android

The bundled inference runtime is based on llama.cpp b12138.
Source: https://github.com/ggml-org/llama.cpp/tree/f7b41cca4fecc8164c7ea45bfb55dfff7633842f
The Android project includes the patch used for this build.

The optional Vulkan backend loads Mesa Turnip 26.2.6, built by nihui.
Android build source: https://github.com/nihui/mesa-turnip-android-driver/tree/26.2.6
Mesa source: https://gitlab.freedesktop.org/mesa/mesa/-/tree/mesa-26.2.6
Mesa component licenses: https://gitlab.freedesktop.org/mesa/mesa/-/tree/mesa-26.2.6/licenses

The APK includes libc++_shared from Android NDK r27d.
The NDK toolchain notice is included in this directory.
